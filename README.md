## Notes:
S/w programming is all about solving real time problems that has large amount of data and requirement to manipulate the data.
How C++ work?
Step1: Define the problem to solve.(What)
Step 2: Design a solution. (Paper work).(How)
Step 3: Write a program that implements the solution. 
Step 4: Compile the program.(Its a process of a C++ Environment to check if all the syntax and the grammer is proper or not).
Step 5: Link obj files.
Step 6: Execute UR program and test it on all permutations and combinations. 

Write a Calc program that shall perform arithematic calculations?
Create a new Cpp file and start implementing the functionality. UR code should be modular in nature. One function should do only one job. 

Analogy of modularity in real world:
Taking Choice should a function
Taking input Values should be another function
Computation should be another function
Displaying the result shall be an another function. 


C++, Java, C#, Python and scripting languages are high level languages. This programming language is created using plain english understandable to humans which gets converted into machine language(Binaries) so that it shall instruct the machine on what it needs to do. 
The process of conversion is called as COMPILING. 

IDEs are typically used to do all the things together, maintain the code, get intellisense support for faster coding and fixing the bugs.

Mac: CLang++ 8/VS Code
Windows: Visual Studio.
